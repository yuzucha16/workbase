# logbook

期限のあるナレッジの置き場。`exmem/lessons/`（長く効く判断・原則・落とし穴）と分けて、時間が経つと古くなる記録をここに置き、定期的に畳む。置き場は【仮 〜2026-11-29】（月次の振り返りで確かめる）。決定の経緯は、閉じたトピック `logbook-design` の決定として `docs/decisions.md` に統合した（2026-10-30）。

このリポジトリは公開なので、世界に読まれる前提で書く。機密、勤務先に固有の情報、PC ごとのデータ、個人を特定する内容を入れない（ルートの `AGENTS.md` の「共有の範囲」）。

## 入るもの・入らないもの

| 型 | 置き場 |
|---|---|
| ① 時系列で増える観測・測定（実測値、件数の推移など） | `logbook/` |
| ③ 試行の途中（結論の出ていない試し） | `logbook/` |
| ② 版・時点に縛られる事実 | 入れない。`exmem/lessons/` の節のまま、見出しの直下に `<!-- 版依存: 一方向\|並存 / 確認: 日付 -->` を付ける（1 つの lesson が 2 ファイルに割れて二重管理になるため） |
| 個人の好み、1 回きりの構成記録 | 入れない。ユーザーが直接削除する |
| 素材（履歴の種など） | 入れない。`exmem/lessons/` の節のまま、見出しの直下に `<!-- 素材: 開始時に読まない / 確認: 日付 -->` を付ける（2026-10-27 ユーザーの決定。`shell-command-usecases` の 2 節） |

## 型

### ファイル名

- lesson からファイルごと移すものは、名前を保つ（例: `user-thinking-habits.md`）。
- lesson の一部（節）を移すものは `<lesson の名前>-log.md`（例: `ai-work-metrics-log.md`）。lesson と同名にすると「ファイル名は Vault 内で一意」に反し、`[[リンク]]` の行き先が決まらない。
- 新規は、lesson と重ならない名前にする。 名前の規則の全体は `workflow-kit/naming-rules.md`。

### frontmatter

```yaml
---
type: logbook
title: AI 作業の実測値
source: "[[ai-work-metrics]]"   # 降格元の lesson。新規なら書かない
created: 2026-10-26
updated: 2026-10-26
review_by: 2026-12-25            # 作った日・判断した日から 60 日（暫定）
budget: 8KB                      # 大きさの上限（暫定）
---
```

- 必須は `type`（`logbook`）、`title`、`created`、`updated`、`review_by`、`budget`。`source` は降格したときだけ。
- `tags` `aliases` `triggers` は付けない（`triggers` の扱いは `docs/due.md` の 2026-11-08 で決める）。
- 既定の `review_by` 60 日と `budget` 8KB は根拠の無い目安。2026-11-29 の月次の試行の後に、実測で直す。

### 節

- `## いま`: 要約。これだけ読めば使える。降格したものは先頭に `元: [[lesson]]` を 1 行。
- `## 明細`: 日付つき、新しい順。開始時に読まない。

## 降格（lesson → logbook）

- 降格するか（①③ の節か）は、承認の 3 段チェック（`workflow-kit/approval-screening.md`）で決める。確認の単位はファイル、降格の単位は節。
- lesson の側は、移した節の位置に結論 1 行と `→ [[<名前>-log]]` を残す。
- 明細は原文のまま移す。圧縮は降格とは別の判断にする（1 つの承認にまとめない）。

## 畳み方

点検は `python -I workflow-kit/tools/find_knowledge.py --check-aging`（`review_by` を過ぎたもの、`budget` を超えたもの、frontmatter が欠けたもの）。`review` の入力 3 で数え、判断は月次の振り返りで行う。

| 畳み方 | すること |
|---|---|
| 捨てる | 役目を終えた記録を消す（削除はユーザーが判断する） |
| 圧縮 | 明細を要約して減らす。`## いま` を更新する |
| 昇格 | 長く効く結論になったものを `exmem/lessons/` へ統合する |
| 延長 | まだ要るなら、判断した日から `review_by` を付け直す |
