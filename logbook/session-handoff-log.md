# スレッドの切り替えと TTL の実験の費用（2026-10-17）

## いま

元: [[session-handoff]]。キャッシュの TTL ごとの費用を、同じ読み取りだけの3ステップで比べた実験と、長い会話の記録の費用の内訳。Sonnet 5.5、1回ずつ、クライアント側の概算。単価や TTL の既定が変わると数字は変わる（TTL の既定の事実は lesson の Facts に残した）。

- 6分あけると、5分TTL は1時間TTL より約 $0.11 高い（$0.387 と $0.276）。
- 長い会話の費用は、書き込みが半分以上を占める。

## 明細

確認日はいずれも 2026-10-17。

- 同じ読み取りだけの3ステップを、条件を変えて実行した。会話をつないで続けて実行は $0.121、別の会話で3回は $0.130、6分あけて1時間TTL は $0.276、6分あけて5分TTL は $0.387（Sonnet 5.5。1回ずつ。クライアント側の概算）（根拠: `claude -p --output-format json` の `total_cost_usd` を4条件で実行して比べた）。
- 5分TTL で6分あけると、間のたびに会話の大半（5.8万〜6.7万トークン）を書き直し、1回あたり約20〜22円（1ドル158円）増えた（根拠: 同じ実行の `usage` の書き込みと読み出し）。
- 1時間TTL の最初の書き込みの割増（約$0.13）は、間が1回空けば取り戻せる（仮説）。補足: 1回ずつの実行で、他の条件が先に温めた共通の先頭を1時間側が読めなかった影響も混ざる。
- 長い会話の記録の費用は、書き込みが半分以上を占めた。Sonnet 5.5 の部分は書き込み69%、読み出し16%、出力15%。Opus 5.5 の部分は書き込み55%、読み出し33%、出力12%（定価での推定。メインの会話のみ）（根拠: 会話の記録の `usage` を `message.id` で重複を除いて集計）。
