# 憲章・WBS・マイルストーン: セッション別トークン・コスト可視化

元は [[usage-viz-6r]]。作り方のメモは [[usage-viz-plan-notes]]。

## 憲章

| 欄 | 内容 |
|---|---|
| 名前 | セッション別トークン・コスト可視化 |
| 更新日 | 2026-10-20 |
| 使命（What） | セッション単位のトークン・価格・キャッシュ利用を、CLIで集計・順位付け・傾向表示できるようにする |
| ビジネスの目的（Why） | 使用量が多い条件を見つけ、使い方の見直しに使う |
| 完了時期 | 2026-10-26（バッファ込みで10-28） |
| 予算 | 5稼働日（平日のみ） |
| 品質 | 合計が突合先と±5%以内で一致する。価格表に出典がある |
| 指標 | 直近7日分の全セッションを集計でき、差が±5%以内 |
| メンバー | ユーザー、AI |
| リーダー | ユーザー（兼任） |
| オーナー | ユーザー |
| 必要なマイルストーン | M1 10-21、M2 10-23、M3 10-26 |

## 成果物 WBS

```
1 セッション別使用量可視化CLI
 1.1 要件
  1.1.1 集計項目の定義書（トークン種別・期間・キャッシュ利用率の式）
  1.1.2 モデル別の価格表（出典・取得日つき）
 1.2 データ
  1.2.1 ログの所在と形式の確認メモ
  1.2.2 動作確認用のサンプルデータ（匿名化）
 1.3 集計
  1.3.1 セッション別の集計（トークン・価格・キャッシュ）
 1.4 出力
  1.4.1 ランキング出力（トークン順・価格順）
  1.4.2 傾向出力（日別・モデル別・セッション長別）
 1.5 検証
  1.5.1 突合結果（既存ツールまたは /cost との比較）
 1.6 運用
  1.6.1 定期確認の手順書（コマンドと見方）
2 プロジェクトマネジメント
 2.1 憲章
 2.2 WBS
 2.3 マイルストーン
 2.4 課題ログ（条件付き）
 2.5 使い心地の記録
```

## マイルストーン（1週間、上限3つ）

| # | 日付 | 内容 | 置く基準 |
|---|---|---|---|
| M1 | 10-21（水） | 1.1・1.2 完了。ログ形式と価格表が確定 | 成果物の作成完了 |
| M2 | 10-23（金） | 1.3〜1.5 完了。集計・ランキング・傾向が動き、突合が済む | 成果物の作成完了 |
| M3 | 10-26（月） | 1.6 完了。オーナーが定期確認の手順をレビューして確定 | オーナーのレビュー |
