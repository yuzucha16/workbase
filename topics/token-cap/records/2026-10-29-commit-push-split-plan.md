## ee の疑問への答え（規則は小難しくないはず）

通常のコミットの核は「パスを指定して add → diff の行数を確認 → agent の身元とトレーラーで commit → 報告」で、小難しくない。長くなったのは、並行セッションの巻き込み、分割コミット、`rebase`、クラウドの使い捨て環境、公開リポジトリの検索など、一度起きたことや個別の決定を、そのつど同じファイルに足したため。まれな場面を毎回読んでいたのが重さの原因。
