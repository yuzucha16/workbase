# kit-growth inbox（未選別の印象）

PC1 などで使った印象を、帰り道の壁打ちのあとに1行ずつ足す。`review` が未選別の件数を見る。取捨選択して、大事なものを子トピック（Project 型）にするか、`docs/decisions.md` に決定として残す。選別が済んだ行は「選別済み」へ移す。

## 未選別

- 2026-10-15 少し: 他環境の文書を画像で渡されたので、読み取りに手間取った（原因: 画像の切れ目で欠落、判読不能、一時ファイルの残り）。画像の文書を取り込むときの型（欠落の一覧を先に出す、固有名の扱いを先に決める）が kit に無い。

## 選別済み

- （topic-workflow から移した）handover・next-steps・roadmap は、名前と内容が一致していて、log・decisions より分かりやすい。いずれ両方の良いところを取る。いまはフックの再利用を優先して docs の名前にしている（2026-10-15）。 → 見送り: log/decisions のまま進める（他セッションで決定。2026-10-15、ユーザー）。
