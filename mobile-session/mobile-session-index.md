# mobile-session

モバイル（クラウド）のセッションで検討したことを、リポジトリのあるデバイス（PC）のセッションに引き継ぐ置き場。

## 使い方

- 話題ごとにディレクトリを作る（例: `ai-workspace-boundary/`）。
- 各ディレクトリの入口は `*-handover.md`（背景・決定・必要情報）と `*-next-steps.md`（次のステップ）の2つ。PC のセッションには、この2つを読ませれば足りる。詳細な設計ノートは同じディレクトリに置く。
- ファイル名は、リポジトリ内で一意にする（wikilink が最短パスで解決されるため）。
- 引き継いだ内容を正式な場所（`exmem/lessons/`、`workflow-kit/` など）へ反映したら、その話題ディレクトリは削除してよい（履歴は git に残る）。

## 話題

| ディレクトリ | 内容 | 状態 |
|---|---|---|
| `ai-workspace-boundary/` | AI に見せる領域・見せない領域の境界（AI 作業部屋の設計） | 検討を終え、PC で検証・実装へ（2026-10-12） |
