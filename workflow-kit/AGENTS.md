# AGENTS.md

このディレクトリ（workflow-kit）は、全作業ディレクトリが参照する共通機能の正本。変更の影響が広いので、次を守る。

- **ユーザーの承認なしに書き換えない。** 改善提案は `knowledge-hook.md` の「このフックの改善」の流れで出し、承認後に直す。
- **特定のディレクトリの固有事情を書かない。** 固有のルールは、各ディレクトリの `AGENTS.md` に置く。ここに書くのは、どのディレクトリでも成り立つことだけ。
- **共有側のファイルなので、機密・ユーザー名・会社名・URL の秘匿値を書かない。** `_local/` や `projects/` `areas/` へ `[[リンク]]` を張らない。
- **各ディレクトリの薄い `AGENTS.md`（`templates/AGENTS.md`）の項目は、増やさない・変えない。** 変えると、既存の全ディレクトリに影響する。変えるときは `improvements.md` に理由を残す。
- 変更したら、`README.md` の変更履歴に1行足す。改善提案から直した場合は `improvements.md` も更新する。
- ファイル形式の正本はここにある。`exmem/inbox/README.md` など他所に同じ形式を写さず、ここを指す。
- コミットメッセージは `[workflow-kit] 内容`。`notes` のコミット・push はユーザーが行う。
