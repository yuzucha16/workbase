# AGENTS.md

このディレクトリ（workflow-kit）は、全作業ディレクトリが参照する共通機能の正本。変更の影響が広いので、次を守る。

- **ユーザーの承認なしに書き換えない。** 改善提案は `hook-common.md` の「改善」の流れで出し、承認後に直す。例外は無い（`wrap-hook.md` の自動採用の仕組みは、2026-10-15 に畳んだ）。
- **特定のディレクトリの固有事情を書かない。** 固有のルールは、各ディレクトリの `AGENTS.md` に置く。ここに書くのは、どのディレクトリでも成り立つことだけ。
- **共有側のファイルなので、機密・ユーザー名・会社名・URL の秘匿値を書かない。** このリポジトリの外（ワークスペースの `areas/` `projects/` `archives/` など）のファイルへ `[[リンク]]` を張らない。
- **各ディレクトリの薄い `AGENTS.md`（`templates/AGENTS.md`）の項目は、増やさない・変えない。** 変えると、既存の全ディレクトリに影響する。変えるときは `topics/kit-growth/docs/decisions.md` に理由を残す。
- 変更の理由は、コミットメッセージに書く（版番号と README の変更履歴は廃止。`git log -- workflow-kit/`）。改善提案から直した場合は、`topics/kit-growth/docs/decisions.md` に1行足す（`improvements.md` は 2026-10-15 に凍結。追記しない）。
- ファイル形式の正本はここにある。`exmem/inbox/README.md` など他所に同じ形式を写さず、ここを指す。
- コミットメッセージは `[workflow-kit] 内容`。コミットは `docs-rules.md` の「コミットと push」に従う（kit の変更は、承認を得た後）。push はユーザーが行う。
