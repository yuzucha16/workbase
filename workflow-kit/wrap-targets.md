# wrap の対象が決まらないとき

`wrap-hook.md` の手順 1 で、既定（作業した単位の `docs/` と、変更したリポジトリの `docs/`）が当てはまらないときだけ読む（2026-10-29 に `wrap-hook.md` から分けた。全文読みを減らすため）。

- 変更したリポジトリに `docs/` が無く、そのリポジトリの `AGENTS.md` が `wrap` の既定の対象を定めていれば、それを対象にする。
- リポジトリの外だけを変えたとき、または変更したリポジトリに `docs/` も既定の対象も無いときは、親の works の `docs/`、それも無ければ、Claude Code を開いた作業ディレクトリの `docs/` を対象にする（別のリポジトリなので、そのリポジトリでコミットする）。
- exmem だけで進めた作業は、該当する `exmem/lessons/` のノートの `Open Questions` / `Next Actions` を更新する。
- どれも無ければ、手順 1 を省略して、報告に書く。
