# 振り返りの出力の型1（定期）: daily / weekly / monthly の規模と章立て

[[retrospective-method]]（改善4）の、応答の形だけを切り出したノート。依頼の言葉（「振り返って」「daily」など）で、このノートだけを読み、この形で返す。やり方の全体（評価軸を先に決める、事実を一次記録から数える、など）は元のノートにあり、`brief 改善` で読む（2026-10-28 に切り出した。開始時の読み込みを 約 24k から 約 3k に下げる試験。`topics/token-cap/records/2026-10-28-brief-mode-load.md`）。

突発の失敗・トラブル1件を掘るときは、[[retrospective-method-2-output]] の形にする。

## 作り方の Must（3つ）

1. 周期（daily / weekly / monthly）を最初に宣言し、下の規模を超えない。超えるものは書かない（畳む）。
2. 評価軸は、材料（出来事）を読む前に決める。良い点と悪い点を両方探す。
3. 悪い点は、人の注意不足で終えず、仕組みの欠けまで書く。施策は承認待ちとして出す。

## 規模

| 周期 | 章数 | 読了 | 本文の字数（表を含む） | 章 | いつ |
|---|---|---|---|---|---|
| daily | 3まで | 1分 | 500字 | 0 サマリ / 4 評価 / 6 施策 | 言われたときだけ。期日のリマインドは無し（2026-10-25 ユーザー、「毎日出てきて面倒」） |
| weekly | 4まで | 2分 | 1,000字 | daily に 3 事実の一覧を足す | 7日周期。日曜（2026-10-25 の次は 11-01） |
| monthly | 5まで | 3分 | 1,500字 | weekly に 7 限界を足す。週次の記録を並べて、繰り返しを探す | 28日周期。日曜（2026-10-25 の次は 11-29）。2026-10-25 のユーザーの決定で、月末基準から変えた |

章の番号は v5 のまま。章 1（目標は冒頭の1行）、章 2（軸は既定を使い、差分は1行）、章 5（章 4 に統合）、末尾の章は持たない。daily は事実の ID を持たず、サマリと評価の文に出来事を1語で添える。読了は字数（日本語 約500字/分）で見る。

## 章立て（章は固定。調査1・調査2に倣う）

倣った点: 調査1は「章ごとに含めるものを添える」、調査2は「章を固定し、各手順を同じ型にする」。振り返りでは、**章を固定する**。v5（2026-10-19）で、章を 11 から 8 に減らし、次の3つの分け方を入れた。省く・足すのは仕込みで決め、省いたら理由を章 7 に書く。

- **流れは「目標 → 現状 → ギャップ → 施策」**。サマリと章 1・4・5・6 がこの順に対応する。
- **対象を分ける**。章 4 は活動（人の進め方・判断）、章 5 は成果物（データ・手順書・スクリプト）。悪い点は所在（目標 / 行動 / 仕組み）を付ける。
- **抽象度を分ける**。具体の出来事（日付、コミット、件数）は章 3 の事実の一覧（ID 付き）だけに置く。サマリと章 4・5・6 は仕組みの話だけを書き、事実は ID で指す。

**v6（2026-10-20）**: 下の表は全章を載せた v5 の完全版。実際に書く章は、周期ごとの規模（上の「規模」）に収める。表の「含めるもの」のうち、規模に入らないものは書かない。個数の上限（各最大3個）は畳んだ。

| 章 | 見出し | 含めるもの |
|---|---|---|
| 冒頭 | 版の行 | 作成日、対象、期間、読者、用途、状態（叩き台 / 承認済み） |
| 0 | サマリ | 読み手が最初に見る章。(a) 4行: **目標 / 現状 / ギャップ（最大の1つ）/ 最優先の施策**。(b) 手戻りの件数と母数（1行。事実の一覧の入口）。(c) 良い点・悪い点の対の表（対象=活動/成果物、軸、一言、所在、章 4.n / 5.n への参照）。(d) 施策の件数と、承認が要るもの。(e) 範囲と限界の一言。(a)(d)(e) の文の合計が300字以内（表を除く）。本文の結論だけを書き、本文に無いことは書かない |
| 1 | 目標と範囲 | **目標**（あるべき姿 1〜3行と出どころ）、対象（活動 / 成果物 / 両方）、期間・件数、一次記録の表（記録、件数、取得日。二次の資料があれば区分を付ける）、**見えない範囲**（別 PC、別スレッド、口頭） |
| 2 | 評価軸の設計 | 下の「評価軸の設計」を表で。軸ごとに 対象（活動/成果物）/ 名前 / 何を見るか / 良いの条件 / 悪いの条件 / 数え方 / 探索（良い・悪いの候補の件数。無いときは「探したが無かった」）。軸は3〜5個、省いた候補とその理由。軸は目標から導いた旨を1行 |
| 3 | 事実の一覧 | **具体はここだけ。** 軸ごとの、ID（F1…）・日付・出来事・出典の表。数え方の定義（何を1件とするか）、母数。手戻り・撤回・差し戻し・再依頼・中断の件数は AI が材料から数える（自己申告で代えない） |
| 4 | 活動の評価 | 進め方・判断について、良い点 `4.n+`（要因、再現条件）、悪い点 `4.n-`（所在、仕組みの欠け、影響）。各節は、事実の ID、目標とのギャップの1行を添える。人の注意不足で終えない |
| 5 | 成果物の評価 | 成果物について、章 4 と同じ型 |
| 6 | 施策（承認待ち） | 表: ID / 種別（再現 / 補正）/ 対応する節 / 内容 / 反映先 / 優先度（影響度×支配度）/ 検証項目 / 状態。前回の施策があれば、効いたかを先頭に（実測と自己採点を区別）。大きいものは「改善へ渡す」 |
| 7 | 解釈・推測・限界 | 事実と区別した解釈の弱い箇所、【推測】とその根拠、1事例からの飛躍、母数の小ささ、見えない範囲の影響、省いた軸と理由、選ばなかった良い点・悪い点の件数、軸の偏り、既定として置いたもの |
| 末尾 | 遠回り・次の一手 | この振り返り自体の手戻り（次回に回す）。次の振り返りの時期 |
