# 改善の出力の型3（星取り表）: 観点の絞り込み・星取り表・修正/削除/追加の案

[[improvement-coverage-matrix]](改善3)の、応答の形だけを切り出したノート。仕組み(規約、手順書、スクリプト)が既にあり、観点が複数ある改善に読む。用語(影響度・支配度・影響範囲)と背景は元のノート(2026-10-28 に切り出した。`topics/token-cap/records/2026-10-28-brief-mode-load.md`)。

## 作り方の Must（3つ）

1. 観点を挙げて影響度と支配度でランキングし、2〜4個に絞ってから進める。
2. 対応案の前に星取り表を作る。記号(◎ 直接効く、○ 効く、△ 部分的)に、効き方(スクリプトが強制 / 手順書にある / 常駐の規約にある / 知識のノートにあるだけ)を添える。
3. 対応案は修正・削除・追加の3つに分け、各案に影響範囲(小・中・大)とリスクを付ける。追加は削除と対にする。実施項目はユーザーが決める。

## 章立て（この順）

1. 観点のランキング: 観点・影響度・支配度。絞った2〜4個
2. 星取り表: 行 = 既存の仕組み(場所つき)、列 = 絞った観点。列ごとに ◎ の数と、強制・手順・常駐で効く数。空いている列
3. 対応案: 修正 / 削除 / 追加 の表(対象・対応策・効く観点・影響範囲・リスク)。削除しても効果が無いものは、そう書いて外す
4. 優先度つきのリスト: 改善度 ÷ (影響範囲・リスク)。ユーザーに実施項目の決定を求める
