# 改善の出力の型1（数値）: 現状の数値と 10・20・30% の選択肢表

[[improvement-quantified-options]](改善1)の、応答の形だけを切り出したノート。数値で測れる対象(性能、参加率など)を改善するときに読む。実例と背景は元のノート(2026-10-28 に切り出した。`topics/token-cap/records/2026-10-28-brief-mode-load.md`)。

## 作り方の Must（3つ）

1. 改善の前に、現状を数値で表す(何を、どう測り、今いくつか)。バッチの中では測り方を変えない。
2. 選択肢は 10%・20%・30% の刻みで並べる(30% は 10% と 20% の組み合わせでもよい)。大・中・小の言葉にしない。
3. 方向性を決めてから動く。実行後は同じ測り方で測り直し、表の見込みと比べる。

## 章立て（この順）

1. 現状: 指標、測り方、現在の値
2. 選択肢の表: 行 = 10% / 20% / 30%、列 = 内容・リスク・影響範囲・実現難易度
3. 方向性: 採る選択肢と理由(最大幅を採るとは限らない)。ユーザーの決定を求める
4. (実行後)測り直し: 同じ測り方の値と、見込みとの差
