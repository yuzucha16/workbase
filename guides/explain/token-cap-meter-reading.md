# トークン上限の数え方と、会話を切る目安の効き方

## 冒頭
月次のトークン上限（量で数える）に対して、なぜ「会話を切る」が一番効くのかを、実測の数字で自分で説明できるようにする。前提: AI の各応答は、会話の履歴全体を入力として読み直す。上限は各応答の入力の合計に数えられる（キャッシュ読みを含む想定。上限を定めた側の数え方は未確認）。確認状況: 1 台の PC の実測（70 会話、2,412 応答）で確認。

## ダイジェスト
- 状況: 月 2億の上限に対し、1 台の PC だけで合計 2.33億（116%）に達した。60k を超えた応答が、件数で 74%、トークンで 89% を占めた。
- 原因: 応答のたびに会話全体を読み直すので、会話が長いほど 1 応答の入力が増え、合計は「会話の大きさ × 応答数」の積み上げになる。平均は 1 応答あたり約 96.5k だった。
- 解決: 会話を 60k で切る。同じ作業量で、1 応答の平均が約 96.5k から約 44k になる見込み（約 54% 減）。次に、毎回読む固定の分（土台）を削る。

## 基礎知識
- **会話の大きさ**: 直近の応答の入力・出力・キャッシュの合計。Zed のチャット欄下の表示はこれで、累計ではない。応答のたびに置き換わり、圧縮すると下がる（確認: 2026-10-26、根拠: ACP アダプタ 0.95.0 の配布物のコード）。
- **土台（ベーストークン）**: 会話の最初の応答の大きさ。ツール定義、skills、memory、AGENTS.md などの常駐分。会話ごとの差は小さく、この PC では 27.5k〜30.3k（中央値 27.9k）。全応答が毎回読むので、合計の 29%（土台 × 応答数）になる。
- **上限に数えられる量**: 各応答の入力の合計。会話の大きさ × 応答数。表示の値を、応答のたびに足していくイメージ。
- **切ったときの平均**: 会話が土台 B から切る大きさ C まで一定の割合で伸びるなら、1 応答の平均の入力は (B + C) / 2。B = 28k なら、C = 60k で 44k、C = 50k で 39k、C = 100k で 64k。60k 以下の応答の実測の平均は 41k で、式とほぼ合った（確認: 2026-10-26、根拠: 70 会話の集計から導出）。
- **切ると土台の割合が上がる**: C = 60k では、トークンの約 63% が土台（28k ÷ 44k）。切る前は 29%。だから順序は「切る → 土台を削る」で、土台を 6k 減らす効きは、切る前の約 6% から、切った後の約 14% に上がる。
- 引継ぎの手間: 会話を増やすと土台の読み直しが増えるが、会話が倍になっても約 5M（全体の約 2%）で、切る効果より小さい。
- 自分で説明するときの一言: 「AI は毎回、会話の全部を読み直すので、使用量は会話の長さの足し算になる。長くなる前に切ると、1 回あたりの読み直しが半分になる」

## チェックリスト
| 症状 | 原因 | 対処 |
|---|---|---|
| 表示の値は小さいのに、月の合計が上限を超えた | 表示は直近の会話の大きさで、累計でない。合計は応答数ぶん足される | 累計は記録から集計する（`cap_meter.py`）。表示は「切る時機」の判断にだけ使う |
| 月末の見込みが大きく出る | 日割りの単純計算で、使い始めが月の途中だと過大になる | 使った日数で割り直す。日ごとの値を見る |
| 60k 超の応答が少数なのにトークンの大半を占める | 長い会話の応答ほど入力が大きい（この PC では 60k 超の平均が約 115k） | 切る目安を守った前後で、割合と平均を比べる |
| 土台が `/context` の値より大きい | 最初の応答の cache 書き込みなどを含む可能性（仮説） | `/context` の内訳で、減らせる分（skills、memory）を見る |

## 補足
| 切る大きさ C | 1 応答の平均（B = 28k） | 今（96.5k）に対する削減 |
|---|---|---|
| 100k | 約 64k | 約 34% |
| 60k | 約 44k | 約 54% |
| 50k | 約 39k | 約 60% |

- 作業に使える幅は C − B。C = 60k、B = 28k なら 32k。フックの読み込み（約 1.2万）を足すと 2 万前後に狭まる。
- 前提: 応答数が同じ、伸びが一定、引継ぎの手間は無視。実測で直す。

## 要確認事項
- 上限を定めた側の上限が、キャッシュ読みを含む総量か、モデルで重みが違うか。
- 土台の 27.9k と `/context` の 19.4k の差（約 8k）の中身。
- 60k 運用を始めた後（10-27 以降）の実測が、見込みの約 54% 減に近いか。
