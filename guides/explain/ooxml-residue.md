# xlsx・pptx で、消したはずの情報が残る仕組みと、AI に渡す前の点検・掃除（理解ガイド）

シートや個人名を消したブック・資料を AI に見せたら、消したはずのものが見えていた。なぜそうなるかと、AI に渡す前に `cleankit.py`（`workflow-kit/room/`）で点検・掃除するときの考え方を、自分で説明できるようにする文書。語の置換（マスク）は [[ai-room-mask-summary]]、マスクの仕様は `workflow-kit/room/mask-spec.md`。

> **状態: 草稿（未レビュー）。** 2026-10-26 のスレッドで、ダミーのファイル（openpyxl・python-pptx・LibreOffice 26 で作成）を使って確かめた。Excel・PowerPoint 本体での確認は未了。

## 1. 仕組み: 画面と中身は別

- xlsx・pptx は zip。中は部品（part）の XML で、部品どうしを `_rels/*.rels`（関係）が結ぶ。アプリは関係をたどって表示する。
- AI は画面ではなく、zip の中の XML を読む。だから、**画面から見えないものも、zip に入っていれば AI に見える**。
- 「見えない」は「入っていない」ではない。非表示シート（`hidden`、画面から再表示できない `veryHidden`）、非表示の行・列、スライドの外に置いた図形、非表示スライドは、中身がそのまま XML に入っている。
- 「削除」も、消えるのはその部品だけ。**ほかの部品が持っている写し（キャッシュ）は残る**。グラフは元データの値を、ピボットは元データ全件を、外部リンクは相手のブックの値を、自分の中に写して持っている。

## 2. 残り方の一覧

| 場所 | 残るもの | 確かめ方 |
|---|---|---|
| グラフ（`charts/chartN.xml` の `strCache` / `numCache`） | 元データの項目名と値、参照先のシート名 | ダミーで確認（シートを消しても、グラフが写しで描かれ続ける） |
| ピボット（`pivotCache/`） | 元データの全件 | ECMA-376 の構造 |
| 外部リンク（`externalLinks/`） | 相手のブックのパス、シート名、値 | 同上 |
| 定義名（`workbook.xml`） | 名前と元の参照。参照先を消すと `#REF!` になるが、名前は残る | ダミーで確認 |
| 共有文字列（`sharedStrings.xml`） | 非表示シートだけが使う文字列、どこも使っていない文字列 | ダミーで確認 |
| コメント（`comments`、`threadedComments`、`persons`） | 本文、作成者名、利用者 ID | ダミーで確認 |
| 文書プロパティ（`docProps/`） | 作成者、最終更新者、会社、シート名の一覧（`TitlesOfParts`）、秘密度ラベル | ダミーで確認 |
| `workbook.xml` の `x15ac:absPath` | 保存した場所の絶対パス（Windows のユーザー名入り） | ECMA-376 の構造 |
| 接続・クエリ・データモデル（`connections.xml`、`customXml/`、`model/`） | サーバー名、ユーザー名、取り込んだデータ全件 | 同上 |
| 変更履歴（`revisions/`）、プリンター設定、マクロ（`vbaProject.bin`） | 消した値、プリンター名、コード | 同上 |
| pptx の埋め込み（`ppt/embeddings/*.xlsx`） | グラフの元データの**ブック全体** | ダミーで確認 |
| pptx のノート、非表示スライド、コメントと作成者、縮小画像（`docProps/thumbnail.*`） | 文字、1 枚目の絵 | ダミーで確認 |
| zip の構造 | 関係からたどれない部品、同じ名前の重複エントリー（Excel 以外のツールで編集したとき） | 同上 |

## 3. 点検と掃除の考え方

- **マスク（`maskkit.py`）と掃除（`cleankit.py`）は穴が違う。** マスクは `mask.toml` に書いた語を全部品から消すが、書いていない語と構造は残す。掃除は構造（非表示シート、ノート、コメント、プロパティなど）を減らすが、語は見ない。掃除 → マスクの順に重ねる。
- **元ファイルは変えない。** 掃除の結果は別のファイルに書く。掃除の後に、出力をもう一度点検し、XML が読めること・関係の先があること・型があること（整合）も確かめる。
- **報告は AI に見せない。** 報告には、残っていた実データの抜粋が載る。画面に出すのは件数だけ。
- **壊すと困るものは、消さずに報告する。** グラフ・ピボットのキャッシュ（消すとグラフが壊れる。語はマスクで消す）、外部リンク・接続（数式や更新が壊れる）、埋め込み・画像（中身は人が見る）、非表示の行・列（表の形が変わる）、マクロ。
- 掃除の既定と、外し方（`--keep`）は `workflow-kit/room/README.md` の「クリーン化」。

## 4. まだ確かめていないこと

- Excel 本体で、シートを消した後にグラフの写しがどう残るか（LibreOffice は、消したときにグラフを別のセルへ付け替えた。Excel は写しを残すことがある）。実ファイルを点検すると分かる。
- 掃除した出力が、Excel・PowerPoint で警告なしに開くか（LibreOffice では開き、値が保たれた）。
