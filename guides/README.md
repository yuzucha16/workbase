# guides

人（ユーザー）が手順や仕組みを思い出すための文書の置き場（旧 `cheatsheets/`。2026-10-10 に改名）。AI が参考にする知識は `exmem/` に置く。

## 構成

| ディレクトリ | 種類 | 読む人の問い |
|---|---|---|
| `howto/` | 手順書 | どの順で何をやるんだっけ |
| `explain/` | 理解ガイド | なぜそうなる？ どう動いている？ |
| `quickref/` | クイックリファレンス | あのコマンドは何だっけ |

文書の種類の分け方と型は `exmem/lessons/reference-doc-types.md`。

## 入口

- やりたいこと・場面から引く: `guides-index.md`
- 書き方のルール(エージェント向け): `AGENTS.md`
