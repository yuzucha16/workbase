# xlsx・pptx を AI に渡す前に点検・掃除する（`cleankit.py`）

消したつもりのシート・個人名・コメントが、xlsx・pptx の中に残っていないかを確かめ、取り除いた別ファイルを作る手順書。範囲は「元ファイルを用意する」から「AI に渡してよい出力を得る」まで。なぜ残るかは [[ooxml-residue]]、語の置換（マスク）は [[ai-room-mask-summary]]。コマンドの正は `workflow-kit/room/cleankit.py`（`--help` と `profiles`）で、ここには順序と判断だけを書く。

**人が実行する。AI には実行させない**（原本と、残っていた実データを読むため）。報告にも実データの抜粋が載るので、AI に見せない。

## 早見表

| やりたいこと | コマンド |
|---|---|
| 残っているものを一覧にする（ファイルは変えない） | `uv run --script cleankit.py check <ファイル> --report <報告.md>` |
| 既定の強さで掃除する | `uv run --script cleankit.py clean <ファイル> <出力先>` |
| 最も強く掃除する | `uv run --script cleankit.py clean <ファイル> <出力先> --profile strict` |
| strict から画像だけ残す | `… --profile strict --allow images` |
| 非表示の行・列の値だけ空にする | `… --also hidden-rows,hidden-cols` |
| 掃除の動作を1つ外す | `… --keep notes` |
| プロファイル・部品の種類・動作の一覧 | `uv run --script cleankit.py profiles` |

## 仕組み（3つの選び方）

| 選ぶもの | 指定 | 中身 |
|---|---|---|
| プロファイル | `--profile` | 掃除の強さ。`standard`（既定）か `strict` |
| 部品の種類 | `--allow` | `strict` が外す種類のうち、残すもの。`charts` `images` `embeddings` `pivots` `connections` |
| 個別の動作 | `--keep` / `--also` | 既定の掃除から外す / 任意の動作を足す |

プロファイルが足す動作と、部品の種類の意味は次のとおり。一覧は `profiles` でも見られる。

| プロファイル | 残るもの | 外れるもの |
|---|---|---|
| `standard` | グラフ、画像、ピボット、埋め込み、接続、非表示の行・列 | 非表示シート・スライド、ノート、コメント、プロパティ、保存場所のパス、プリンター、縮小画像、変更履歴、外部リンク、使っていない文字列・孤立した部品 など |
| `strict` | 本文、数式、書式 | `standard` の全部と、次の5種類と、非表示の行・列の値 |

| 部品の種類 | 外すと起きること |
|---|---|
| `charts` | グラフが消える（元データのセルは残る） |
| `images` | 画像・図形の絵・背景画像が消える |
| `embeddings` | 埋め込みのブック・OLE が消える（pptx のグラフの元データ全体を含む） |
| `pivots` | ピボットのキャッシュ（元データ全件）が消える。ピボットの表は値として残る |
| `connections` | 接続・クエリ・データモデル・customXml が消える |

マクロ（`vbaProject.bin`）は、どのプロファイルでも消さず、点検で報告するだけ。

## 手順

1. **元ファイルを用意する。** 元のファイルは変わらない。出力先は、このリポジトリ（公開）の外にする（中を指すと止まる）。
2. **点検する。** `check` を実行する。画面には件数だけ出る。終了コードが 0 なら要確認なし、1 なら報告を見る。報告（`.check-report.md`）は実データを含むので、`_noai/` など AI が読めない場所に置く。
3. **強さを選ぶ。** 迷ったら次で決める。

   | 状況 | 選ぶもの |
   |---|---|
   | 表の数値・グラフ・画像が AI に必要 | `standard` |
   | 本文と数式だけで足りる | `strict` |
   | グラフや図は要るが、ピボットの全件は不要 | `strict --allow charts,images` |
   | 非表示の行・列の値が不要 | `--also hidden-rows,hidden-cols`（`strict` には入っている） |

4. **掃除する。** `clean` を実行する。出力を点検し直した結果が「残り」の件数で出る。
5. **残りを確かめる。** 残りが 0 件、かつ「整合の問題」が出ていないこと。残りがあれば報告を見る。残りの代表は、グラフのキャッシュ（`standard`）と、`unseen-text`（見えている文字・固定語に当たらない文字）。
6. **人が開いて確かめる。** 出力を Excel・PowerPoint で開く。**警告が出ないこと**、見た目・数式が崩れていないこと、困る列・行が空になっていないこと（`strict` と `--also hidden-*`）を見る。
7. **語を消す必要があるなら、マスクを重ねる。** 掃除は構造を減らすが、本文の個人名などの語は見ない。掃除 → マスクの順（[[ai-room-mask-summary]]）。
8. **AI に渡す。** 渡すのは出力だけ。報告と元ファイルは渡さない。

完了の目安: 出力を開いて警告がなく、`check` を出力に実行して要確認が出ない（グラフのキャッシュなど、意図して残したものを除く）。

## よく忘れる点

- 報告を AI に見せない。報告は実データの抜粋入り。
- 出力が既にあると止まる。上書きは `--force`。
- 非表示の行・列は、中身を空にするだけで行・列は残る。点検の報告にも出なくなるので、空にしたことを覚えておく。
- 非表示シートを消すと、それを参照する数式は値になる。`calcChain` も外れる（Excel が作り直す）。
- `strict` でも、本文中の語（個人名など）は残る。マスクは別。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| `止めた: すべてのシートが非表示なので…` | 全シートが非表示。`--keep hidden-sheets` で外す |
| `止めた: 出力が既にある` | `--force`、または別の出力先 |
| `止めた: …リポジトリの中…` | 出力・報告の先を、このリポジトリの外にする |
| 整合の問題が出る | 出力を AI に渡さない。報告の該当部品を見る |
| Excel で「パーツがない」などの警告 | 警告の文面（`/xl/…` のパーツ名）を控え、`check` を出力に実行して整合の問題を見る |
| strict の出力で図形が消えて見た目が変わった | 画像・グラフが外れた結果。必要な種類を `--allow` で残す |

## 未確認

- `strict`（部品の種類の除去）は、ダミーのファイルでの単体テストだけ。**実ファイルを Excel・PowerPoint で開く確認は未**。
- 接続（`connections`）を外した後の、テーブルの `queryTable` 設定の残りは未確認（Excel が修復を求める可能性がある）。
- グラフやスライドを AlternateContent で包んだ形（Office の新しい図形）の除去は、合成データでは未検証。
- マクロ入りファイル（xlsm・pptm）の掃除は、点検の報告だけ。
