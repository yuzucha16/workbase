# マスクした資料の要約を出す（復元しない）

顧客情報を含む資料（議事録、事業戦略の資料など）を、AI に原本を見せずに要約・アクション抽出させる手順書。マスクした写しだけを AI に渡し、**実名には戻さない**（読むのは本人だけ）。部屋（`room-<Area>`）は作成済みとする（[[ai-room-setup-script]] の 2 章）。なぜマスクと復元を状態で決めるかは [[ai-room-why]]。

- **ゴール（完了の目安）**: `ai/work/` か `ai/out/` に、プレースホルダー（`⟦CUST_001⟧` など）入りの要約ができ、原本と対応表を AI が読んでいないこと
- 範囲: Project の作成から、要約の受け取りまで。`close` は [[ai-room-setup-script]] の 7 章
- 実機の確認: マスクと復元の通しは確認済み（2026-10-19、ユーザー）。txt の実データでの確認は済み（2026-10-20、ユーザー）。pptx は未了

## 全体の流れ

| 章 | 内容 | 区分 | 完了の目安 |
|---|---|---|---|
| 1 | Project を作る | 手動（`room open`） | `_noai/` に `raw` `map` `final` `user` がある |
| 2 | 原本を置き、語の表を書く | 手動 | `_noai/raw/` に原本、`_noai/mask.toml` がある |
| 3 | マスクして、部屋で要約させる | 手動（`room start`） | 要約ができる |
| 4 | 要約を読む | 手動 | プレースホルダー入りの要約を、人が読む |

## 1. Project を作る

```powershell
uv run room.py open <Project> --area <Area>
```

- `_noai/` には `raw/` `map/` `user/` ができる（`final/` は無い。復元しないため）
- README の本文（目的、完了条件）を書く。ひな形のままだと `close` が通ってしまう

## 2. 原本を置き、語の表を書く

1. 原本（csv・md・txt・xlsx・pptx）を `_noai/raw/` に置く。docx は対象外
2. `_noai/mask.toml` に語の表を書く（`[terms.<種類>] キー = ["正式名", "表記ゆれ"]`、列単位は `[columns]`。書き方は [[ai-room-setup-script]] の 4 章）
3. 人だけで使う仮置きは `_noai/user/` に置く（予約名。`room` も AI も触らない）

- **よく忘れる点**: 雛形の語の行が `#` でコメントアウトされたままだと、何も置き換わらず原本がそのまま `ai/in/` に入る（`mask` が警告を出す）。**辞書にない名前は置き換わらない**。人名は特に漏れる。`mask` の警告（法人格、敬称、メールアドレス、電話番号、URL の形）を見て、必要な語を足す
- 数値は、既定ではマスクしない

## 3. マスクして、部屋で要約させる

```powershell
uv run room.py mask <Project>      # 先に確かめたいとき（start の最初でも自動で行う）
uv run room.py start <Project>
```

1. `mask` が `_noai/raw/` を `ai/in/` にマスクして写す。語が残っていれば止まる
2. 部屋の AI に、`ai/in/` を読んで要約・アクション抽出を頼む。要約は `ai/work/` に置く（`ai/out/` に置くと、終了時に実名へ戻した版が `_noai/final/` にできる）
3. 終わったら、`start` が自動でアンマウントする。要約を `ai/work/` に置いたので、**実名には戻らない**（復元は `ai/out/` だけに掛かる）

- 目安: 「回収: 変更 N 件」に、要約のファイルが出る

## 4. 要約を読む

- 要約はプレースホルダー入り。実名で読みたいときは、`_noai/map/` の対応表（実名入り）を人が見る。AI には見せない
- 実名入りの版が欲しいなら、要約を `ai/out/` に置く（終了時に `_noai/final/` へ復元される。[[ai-room-setup-script]] の 6 章）
- 実名に戻した文書は、works のコミットの対象外（`_noai/` は追跡しない）

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| マスクが止まる | 語が残っている。`mask.toml` に足して、`mask` を再実行する |
